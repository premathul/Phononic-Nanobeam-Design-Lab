# Campaign specifications

Author: **Athul Prem** | Project/file tag: **`_AP_pnc`**

[campaign_template_AP_pnc.json](campaign_template_AP_pnc.json) describes the proposed 3D thickness/temperature/curvature campaign. [material_registry_template_AP_pnc.json](material_registry_template_AP_pnc.json) records nominal historical inputs and explicitly unknown calibration fields. Both are templates: no active solver consumes them, execution is disabled, and resource/property choices must be resolved and validated before use. Do not rename a template as an executed configuration. All length/frequency inputs use explicit units; source CSV coordinates require the stated nm-to-m conversion.
