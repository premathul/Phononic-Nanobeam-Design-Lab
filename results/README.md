[Project home](../README.md) · [Figures](../figures/README.md) · [Verification](../verification/README.md)

For the straight 3D device, start with the [pinned portable dataset](../data/README.md#portable-saved-device-data). The [thin-device research data](../data/README.md#thin-device-research-dataset) include the nine-point grid and companion controls. Full native fields, original detailed reports and resumable checkpoints require the corresponding archive. New outputs under `results/runs/<run_id>/` are ignored by default. Selected compact evidence is committed deliberately with resolved configuration and input/source identities.

| Historical group | Available evidence |
| --- | --- |
| [Smoke runs](archive_smoke) | Available saved runs and the [independently rechecked smoke baseline](archive_smoke/run_new_verified_smoke) |
| [Latest archived nominal cubic-Ge inputs and logs](archive_latest) | Subset of the latest run's inputs, meshes and source snapshots. Missing entries remain identified in the [recovery record](../docs/EVIDENCE_AND_RECOVERY_AP_pnc.md). |
| [Older model and convergence outputs](archive_legacy) | Earlier numerical tables and meshes. Use their own model lineage and dates. |

[Historical documentation](../archive/README.md) explains the predecessor model and original folder layouts. [Provenance](../provenance/README.md) describes the path and hash mapping.
