# Numerical evidence by lineage

Author: **Athul Prem** | Project/file tag: **`_AP_pnc`**

`archive_smoke/` contains the available earlier smoke runs. `archive_latest/` contains only the available subset of latest-run inputs, meshes and source snapshots. `archive_legacy/` contains older tables and convergence meshes. An older table must not be substituted for a missing newer one. Figures are grouped separately in [figures/](../figures/README.md). New future results belong under `results/runs/<run_id>/` with resolved configuration and source/input hashes; that location is ignored until compact, reviewed outputs are deliberately selected for sharing.
