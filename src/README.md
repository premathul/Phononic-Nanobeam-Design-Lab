# Active lightweight source

Author: **Athul Prem** | Project/file tag: **`_AP_pnc`**

[nanobeam_AP_pnc.py](nanobeam_AP_pnc.py) checks simple centerline circular-hole spacing and evaluates an illustrative infinite alternating mass-spring chain. It is not a 2D/3D perforated-beam FEM solver. Run it from the repository root with `python src/nanobeam_AP_pnc.py geometry data/examples/half_array_AP_pnc.csv --beam-width-nm 600` or `python src/nanobeam_AP_pnc.py chain`. The proposed 3D modules are specified in [the AI handoff](../docs/AI_HANDOFF_AP_pnc.md); they have not been implemented by this reorganization.
