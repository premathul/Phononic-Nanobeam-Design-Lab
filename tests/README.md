# Active tests

Author: **Athul Prem** | Project/file tag: **`_AP_pnc`**

Run `python -m unittest discover -s tests -p 'test*_AP_pnc.py' -v` from the repository root. [test_nanobeam_AP_pnc.py](test_nanobeam_AP_pnc.py) preserves four elementary geometry/analytic-chain checks. [test_archive_runtime_AP_pnc.py](test_archive_runtime_AP_pnc.py) checks path/hash/alias/overwrite/completeness behavior. These tests verify the stated utility and evidence-preservation behavior; they do not validate the proposed 3D research campaign.

[test_scattering_AP_pnc.py](test_scattering_AP_pnc.py) checks the complete two-port, power-normalized scattering matrix of a small uniform guide: `S.conj().T @ S = I`. This tests cross-channel orthogonality as well as the separate incident-channel power budgets. An unequal complex superposition incident from both ends also checks outgoing power from the finite-domain nodal forces, independently of the outgoing modal amplitudes. The test preserves the original port reference planes and uses the same port basis for both solves. It verifies lossless coherent-drive consistency for this bounded case, not spatial convergence, reciprocity, or the full patterned device.

The Lawrence h60 workflow tests use small systems to verify exact reconstruction of staged equations, recovery without solving accepted drives again, and rejection of altered data or invalid residuals. The saved-run comparison tests check the reviewed Linux phase and solver provenance. Full-device mesh convergence requires its own physical comparison. [Staging and recovery tests](test_lawrence_device_refinement_AP_pnc.py) · [Saved-run comparison tests](test_compare_scattering_AP_pnc.py)


[Thickness-control tests](test_lawrence_thickness_AP_pnc.py) verify exact in-plane footprint preservation, a SAFE section built without body matrices, variable incident-root identities, interrupted accepted-prefix recovery, and refusal of altered staged equations. The new z4/z6 comparator profile keeps source/SAFE provenance and physical mode matching separate from its scientific acceptance result.

[Frequency-map tests](test_frequency_map_AP_pnc.py) use a 405-DOF right-incident guide at 0.25/0.30/0.35 GHz. They compare each response against an independently assembled single-frequency direct solve, replay original equations and nodal-force flux, interrupt and resume without repeating accepted work, and preserve a sampled cutoff failure while breaking the mode track across the gap. Synthetic signed-mode permutations and complex gauges check cumulative channel alignment, while changed inputs and saved scientific artifacts are rejected. These small workflow checks do not establish full-device spatial or frequency convergence.

[Archived frequency-map tests](test_imported_frequency_map_AP_pnc.py) exercise archive path containment and streamed checksum verification. They reject changed equation identities, residual gates, scientific inputs, Linux source provenance and published files. Small fixtures check signed channel ordering, distinct relative and backward residuals, pending frequencies, all three failed complex-response mesh comparisons and reuse after relocation. The import tests block numerical computations and loading large scientific arrays. The separate real-archive check verifies the saved 1 GHz response and its 26 referenced artifacts. [Archived map evidence](../verification/imported_frequency_map_AP_pnc.json)

The uniform-control tests also check the h80 default and separate h60 receipt/configuration selection, rejection of an h60 iterative solve or historical h80 preflight exception, and preservation of exact K/M/A/RHS before a refused factorization. Small dense-reference solves retain the original residual gates. The comparator accepts only the pinned new driver within its reviewed fixed-port 3 micrometre h60/h80 scope and continues to accept the archived h80 source.

[Port-inventory tests](test_port_inventory_AP_pnc.py) use an 18-DOF section with closed-form coupled-helicity and scalar quadratic roots. They compare every root with the analytic spectrum, replay signed physical flux, retain an actual synthetic cutoff failure, interrupt and resume only pending frequencies, preserve the archived anchor and verify unchanged output bytes/mtimes on complete reuse. Tampered scientific receipts and mode arrays are rejected. The separate Windows returned-data replay covers all 9750 roots and 84 published channels from the five real 975-DOF samples without an eigensolve or assembly. These checks verify finite-section algebra and recovery, not continuum convergence or cutoff locations between samples. [Inventory evidence](../verification/port_inventory_AP_pnc.json)

[Low-band workflow tests](test_lawrence_low_band_AP_pnc.py) cover the actual current-helper entrypoint, exact cached equations/export, signed factor-count refusal and recovery of accepted drives. [Independent device replay tests](test_replay_lawrence_device_point_AP_pnc.py) retain all five physical-power gates and add a two-channel case whose individual column powers are unit but whose coherent block defect has spectral norm one. A valid complex-mixing case verifies independent nodal-force superposition and rejects altered forces or cross-direction flux-Gram terms. The real returned h80 z6 point additionally retains the full complex left-incident defect, its spectrum and measured basis departures. This covers only the saved left-incident block; no full two-sided or spatial-convergence claim follows. [Low-band evidence](../verification/low_band_device_AP_pnc.json)
