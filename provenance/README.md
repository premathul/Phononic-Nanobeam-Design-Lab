# Hashes, recovery and attribution

Author: **Athul Prem** | Project/file tag: **`_AP_pnc`**

[relocation_manifest_AP_pnc.json](relocation_manifest_AP_pnc.json) maps all 199 original uploaded paths to their byte-identical successors. [original_flat_manifest_AP_pnc.json](original_flat_manifest_AP_pnc.json) and [original_SHA256SUMS_AP_pnc.json](original_SHA256SUMS_AP_pnc.json) preserve earlier expectations unchanged. [archive_catalog_AP_pnc.json](archive_catalog_AP_pnc.json) resolves 273 expected entries, including 84 exact-hash aliases, while [missing_archive_files_AP_pnc.json](missing_archive_files_AP_pnc.json) records the 223 unresolved entries at reorganization. [file_index_AP_pnc.json](file_index_AP_pnc.json) attributes every committed file to the project and records current hashes. Historical supporting documents/patches remain in `historical/`. A verified alias is identical bytes at another path, not a new result.
