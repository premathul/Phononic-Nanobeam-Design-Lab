## 12 November 2026 reorganization

The [file index](file_index_AP_pnc.json) is the dated 240-entry reorganization inventory. It preserves historical hashes and includes its scope note. Current artifacts use the result receipts above.

- [Relocation manifest](relocation_manifest_AP_pnc.json) maps 199 uploaded paths to their byte-identical successors.
- [Original flat manifest](original_flat_manifest_AP_pnc.json) and [original SHA-256 list](original_SHA256SUMS_AP_pnc.json) preserve the original expectations.
- [Archive catalogue](archive_catalog_AP_pnc.json) resolves 273 expected entries, including 84 exact-hash aliases. Each alias identifies the same bytes at another path.
- [Missing files](missing_archive_files_AP_pnc.json) retains the 223 unresolved entries at reorganization.
- [Original project status](historical/original_PROJECT_STATUS_AP_pnc.md) describes the predecessor 2D work as preserved in the November handoff. Use the [current handoff](../docs/AI_HANDOFF_AP_pnc.md) for active operations.
